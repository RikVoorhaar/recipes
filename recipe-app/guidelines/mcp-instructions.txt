Recipe authoring workflow: call get_guidelines first, save or revise an owner-private draft, read it back with get_draft, validate the candidate, and only then explicitly call publish_draft. By default make one generate_cover attempt for a new dish unless the user opts out; inspect the private preview before explicitly publishing. If generation fails, report it and publish without a cover when requested. Drafts persist across sessions. Do not use HTTP recipe create/update routes for agent authoring.
